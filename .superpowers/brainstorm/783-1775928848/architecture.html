Pourquoi Celery + Redis ?

Les calculs FEM de ViPPer peuvent prendre plusieurs secondes. Avec FastAPI seul, un calcul long bloquerait le serveur pour tous les autres utilisateurs. Celery envoie le calcul dans une file d'attente (Redis), le traite en arrière-plan, et notifie le frontend via WebSocket quand c'est terminé. L'UI affiche une barre de progression en attendant.
