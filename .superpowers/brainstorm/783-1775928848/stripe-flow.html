Intégration Stripe — Flux d'abonnement

Stripe gère tout le paiement. Toi tu n'écriras jamais de code qui touche une carte bancaire.

🚀 Flux Inscription → Paiement
1. Utilisateur crée un compte (Supabase Auth)
2. Choisit son plan (mensuel / annuel)
3. Clique "S'abonner"
4. FastAPI crée une Stripe Checkout Session
5. Redirigé vers page Stripe (hébergée par Stripe)
6. Paiement CB/SEPA saisi sur Stripe
7. Stripe envoie un webhook à FastAPI
8. FastAPI met à jour la table subscriptions
9. Utilisateur redirigé → accès débloqué ✅
🔔 Webhooks Stripe à gérer
✅ checkout.session.completed
→ Créer l'abonnement en BDD
✅ customer.subscription.updated
→ Changement de plan / renouvellement
❌ customer.subscription.deleted
→ Accès révoqué
⚠️ invoice.payment_failed
→ Email relance + accès suspendu

🏦 Stripe Customer Portal — zéro code
Stripe propose un portail client hébergé (configurable dans le dashboard Stripe) qui permet à l'utilisateur de :
→ Changer de plan    → Annuler l'abonnement    → Télécharger ses factures    → Mettre à jour sa CB

Un seul endpoint FastAPI suffit : POST /billing/portal qui retourne l'URL du portail Stripe.
