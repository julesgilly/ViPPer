Schéma Base de Données — Supabase (PostgreSQL)

Les tables grisées sont gérées automatiquement par Supabase Auth. Tu n'as qu'à créer les tables en couleur.

Géré par Supabase Auth
🔒 auth.users
id uuid PRIMARY KEY
email text UNIQUE
encrypted_password text
created_at timestamptz
confirmed_at timestamptz
Tu crées cette table
👤 profiles
id uuid → auth.users.id
full_name text
company text
phone text
stripe_customer_id text
created_at timestamptz
Synchronisé via webhook Stripe
💳 subscriptions
id uuid PRIMARY KEY
user_id uuid → profiles.id
stripe_subscription_id text
plan text -- 'monthly' | 'annual'
status text -- 'active' | 'canceled' | 'past_due'
current_period_end timestamptz
created_at timestamptz
Projets de calcul
📁 projects
id uuid PRIMARY KEY
user_id uuid → profiles.id
name text
client text
data jsonb -- données saisies (sol, charges…)
results jsonb -- résultats calcul
updated_at timestamptz

🔐 Row Level Security (RLS) — Supabase

Supabase permet de définir des règles de sécurité directement en SQL : un utilisateur ne peut jamais voir ou modifier les projets d'un autre. Exemple :

CREATE POLICY "users see own projects"
ON projects FOR ALL
USING (user_id = auth.uid());
